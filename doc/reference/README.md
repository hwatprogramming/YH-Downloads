# Reference material

Drop anything the project is aiming at in here: screenshots, mockups, example
files, saved pages.

Anything shared in a chat is only visible to that session. A later session starts
cold and can't see it, so anything worth working towards has to live in the repo.

Name files for what they show — `login-screen-dark.png`, not `ref3.png` — and
mention the filename in CLAUDE.md wherever it's used as a target.
